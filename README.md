# sportsbuddyBackend

Backend du projet SportBuddy construit avec Spring Boot.

## Prerequis

- Java 17+
- Maven (ou `./mvnw`)

## Lancer en local

```bash
./mvnw spring-boot:run
```

Sous Windows PowerShell:

```powershell
.\mvnw.cmd spring-boot:run
```

## Executer les tests

```bash
./mvnw test
```

Sous Windows PowerShell:

```powershell
.\mvnw.cmd test
```
